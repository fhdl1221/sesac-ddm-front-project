# 냉장고민 - 기능 직접 구현 연습용

이 버전은 **완성본과 파일 구조/컴포넌트 연결을 동일하게 유지하면서 기능 코드만 비워 둔 연습용**입니다.

퍼블리싱(globals.css)과 화면 구조는 완성본 기준으로 유지하고, 기능 구현 위치에는 TODO 힌트를 넣었습니다.

구현 권장 순서:
1. json-server + fridgeApi
2. 내 냉장고 GET/POST/PATCH/DELETE
3. storage 필터 / D-day
4. Zustand + persist + hydration
5. 유통기한 임박 알림
6. Spoonacular 목록
7. 레시피 상세
8. 찜
9. 장바구니
10. 전체 테스트

실행:
- npm install
- npm run server
- npm run dev
